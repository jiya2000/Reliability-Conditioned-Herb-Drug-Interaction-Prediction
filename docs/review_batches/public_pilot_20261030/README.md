# Public evidence pilot — pending human review

This is a real publication-review preparation batch, not a labeled benchmark.
Three candidate pairs cover St John's wort–digoxin, St John's wort–cyclosporine,
and Echinacea–digoxin. Three existing St John's wort target candidates cover
CYP3A4, NR1I2/PXR and ABCB1. Their canonical status has not been changed.

## Collected sources

`source_candidates.json` contains citations, access scope, retrieval date,
paraphrased observations, interpretation cautions and exact-string overlap counts
against the existing canonical evidence table. It contains no reference labels.

- [Johne and colleagues, digoxin study](https://pubmed.ncbi.nlm.nih.gov/10546917/).
- [Bauer and colleagues, cyclosporin study](https://pubmed.ncbi.nlm.nih.gov/12580993/).
- [Gurley and colleagues, comparative digoxin study](https://pubmed.ncbi.nlm.nih.gov/18214850/).
- [Moore and colleagues, PXR/CYP3A4 mechanism study](https://pubmed.ncbi.nlm.nih.gov/10852961/).

The clinical summaries were checked against PubMed abstracts. The mechanism
summary also uses indexed PMC Results/Figure 3 excerpts; direct PMC full-text
access returned a browser challenge. No complete full-text scientific review is
claimed. No copyrighted full article or full abstract has been copied.

Selection is a focused convenience pilot, not a systematic review. These examples
were selected for inspectable primary sources, not to estimate prevalence or model
accuracy. It is small and unbalanced by design. Extend the literature search using
a prespecified review protocol before choosing an evaluation sample.

## Files and reviewer handoff

`packet/` is generated by `src.data.review_packet`. Its consensus reviewer and
adjudication workbooks remain unresolved. The mechanism worksheet remains pending.
`source_candidates.json` is a coordinator/curation aid: do not give these directional
summaries to reviewers expected to derive reference labels independently. Let the
reference reviewers use separately agreed external reference sources and record
circularity checks. Using these studies as both model evidence and reference truth
would not establish independent predictive accuracy.

The comparative digoxin publication concerns both herbs. Its observations cannot
be placed into different Task B roles merely because pair identities differ.
Exact-string source overlap counts are a warning aid only: absent matches cannot
prove independence, because reviews, alternate identifiers and citation chains
may reuse the same evidence.

## Readiness result

`readiness.json` is a structural planning report, not release preflight approval.
The canonical reference table is empty: all three candidate pairs lack reference
labels, and zero binary-labeled pairs are available for every regime. The full
protocol requires five separate roles. No actual assignments have been fabricated.
Even if all three pairs received labels, this pilot has only two herbs and two
drugs and cannot populate five nonempty disjoint roles in any requested regime.
No statistical adequacy or coverage conclusion follows from group counts.

Reproduce from the repository root:

```sh
venv/bin/python -m src.data.review_packet verify \
  --directory docs/review_batches/public_pilot_20261030/packet
venv/bin/python -m src.data.review_readiness \
  --pairs docs/review_batches/public_pilot_20261030/candidate_pairs.csv \
  --consensus data/benchmark/consensus_labels.csv --protocol full
```
